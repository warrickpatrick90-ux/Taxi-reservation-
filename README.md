# Taxi Reservation

A beginner-friendly taxi reservation front-end for Douala and Bonabéri.

## Run it

Open `index.html` in a web browser. No installation is needed.

## What it does

- Choose a pickup and drop-off from 38 listed neighborhoods, or type another area.
- Add landmarks, passenger details, and a pickup date and time.
- Review the booking details in a preview on the page.

This is a front-end demo. It does not send a reservation to a driver or use WhatsApp yet.
